# Chask Swarm Core / Enjambre Chask

*Un Ecosistema de Inteligencia Artificial Autónoma y Descentralizada.*
*An Autonomous and Decentralized Artificial Intelligence Ecosystem.*

---

## 🇪🇸 Español

### ¿Qué es Chask Swarm?
Chask Swarm es una arquitectura avanzada para operar múltiples nodos de Inteligencia Artificial de forma coordinada, privada y autónoma. Se basa en una estructura "Zero-Trust" donde el usuario (El Administrador) mantiene control absoluto sobre los datos, la infraestructura y los canales de comunicación.

### Características Principales
- **Universal e Internacional**: Configurado por defecto para aprovechar la traducción automática del navegador. Soporta cualquier idioma.
- **Protocolo Colmena (Mente Enjambre)**: Delegación automática de tareas complejas a múltiples modelos y agentes especializados (Arquitectos, Investigadores, Auditores).
- **Red Local (LAN Mesh P2P)**: Posibilidad de conectar múltiples PCs en la misma red para distribuir el procesamiento sin salir a Internet.
- **Multi-Modelo**: Soporte para modelos en la nube (OpenRouter, Anthropic, Google) y locales (Ollama).
- **Canales de Comunicación Flexibles**: Controla tu enjambre desde la interfaz web ultra-premium, por consola, o a distancia mediante Telegram.

### Instalación Rápida
1. Descarga y extrae el archivo `Chask_Swarm_Core.zip`.
2. Asegúrate de tener Python instalado.
3. Ejecuta el archivo `instalar.bat` (o instala las dependencias de `requirements.txt`).
4. Abre el panel de control ejecutando `python Advanced_Tools/dashboard/web_dashboard_pro.py` o utilizando los accesos directos.

### Filosofía y Privacidad
El alma de Chask Swarm reside en su negativa rotunda a compartir datos privados con terceros no autorizados. Posee un modo de cuarentena para evaluar documentos externos y un Master Vault para almacenar credenciales de forma segura.

## 🇬🇧 English

### What is Chask Swarm?
Chask Swarm is an advanced architecture to operate multiple Artificial Intelligence nodes in a coordinated, private, and autonomous way. It is based on a "Zero-Trust" structure where the user (The Administrator) maintains absolute control over data, infrastructure, and communication channels.

### Main Features
- **Universal and International**: Configured by default to leverage automatic browser translation. Supports any language natively.
- **Hive Protocol (Swarm Mind)**: Automatic delegation of complex tasks to multiple models and specialized agents (Architects, Researchers, Auditors).
- **Local Network (LAN Mesh P2P)**: Ability to connect multiple PCs on the same network to distribute processing without going to the Internet.
- **Multi-Model**: Support for cloud models (OpenRouter, Anthropic, Google) and local ones (Ollama).
- **Flexible Communication Channels**: Control your swarm from the ultra-premium web interface, via console, or remotely through Telegram.

### Quick Installation
1. Download and extract the `Chask_Swarm_Core.zip` file.
2. Make sure you have Python installed.
3. Run the `instalar.bat` file (or install dependencies from `requirements.txt`).
4. Open the control panel by running `python Advanced_Tools/dashboard/web_dashboard_pro.py` or using the shortcuts.

### Philosophy and Privacy
The soul of Chask Swarm lies in its flat refusal to share private data with unauthorized third parties. It features a quarantine mode to evaluate external documents and a Master Vault to securely store credentials.
